# Process: Compare and check one rule

Concept brand: a portfolio. Two experiences: a 16:9 slide deck and a website.
Shared rules: `design-system.md`. Source image: `Foundations.jpg`.

## 1. Rule being checked

Emphasis word: at most one or two per screen, in Display accent `#B30089`. Action `#F62DAE` is never used for small text or links.

## 2. The one thing that changes

The "Must never happen" list.

- **Version A:** the rule sheet includes the "Must never happen" column.
- **Version B:** the same rule sheet with that column removed. Everything else is identical.

Same task, same attachments (`Foundations.jpg`), same wording otherwise.

## 4. Task prompt (use for both versions)

Run each version in a separate fresh conversation. Do not edit the prompt between runs.

```text
Task: propose one slide for a portfolio deck (16:9) and one matching website section.
Use the attached image and rule sheet.
Propose the layout using my design system.
Keep the named colors, fonts and spacing tokens.
Use this placeholder content and do not add facts: Title "[Project name]", one sentence "[One sentence about the project]".
Choose one emphasis word and say which color it uses and why.
Tell me which files or attachments you actually used.
Say what is unclear.
Show the first proposal and how to check it.
```

Replace the two bracketed placeholders with your own real project name and sentence before running. Use the same text in both versions.
